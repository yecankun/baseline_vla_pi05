# 人工窗口监督的轻量响应编码器：固定对照

2026-09-22，真实拟合前固定。算法轨诊断，不改PI05、mixed-head、控制器或源标签。

## 问题和边界

不再要求自动追踪尖端。用整窗人工的advance/stationary直接监督一个小型响应识别器，
检验“停顿后短时推进”是否在平均汇聚中被稀释。stationary表示无明显推进，允许横向移动；
不等于物理静止、碰壁或无力反馈。没有逐帧推进标签，不生成伪逐帧标签。

这是看完短片后的识别，不是动作前未来预测或候选动作评分。它至多为后续动作效应研究
提供待验证的响应表征；本轮不向PI05/世界模型/实机接入，也不扩大标注/数据。

## 固定数据

- 复用`real10_pre_action_label_retest_v1/annotation_snapshot.jsonl`中的45窗最新批准标签
  （含#100推进、#62无明显推进），25 advance/20 stationary，10个原整episode LOEO折。
  运行前与当前人审源逐窗比对，不改选窗、源all-train身份或人审备注。
- 复用已生成的`real10_response_roi_images_v1`固定场景ROI，602张224×224双视角图；
  不采用挂起的新血管包络，不按预测/人工点移动ROI，不增加图片或新权重。
- ImageNet ResNet18冻结及eval；只提取每帧各512维特征，不用在全部real10上训练的PI05特征。
- 模型输入仅双视角帧序列、task_right、相邻观测可用时间差；不输入控制器状态、事件ID、
  人工可见性/证据视角/坐标、类别、contact/wall/tip/route truth或旧追踪预测。
- 每折只用训练窗口有效帧位置计算每视角特征均值/std、时间差均值/std，标准化后clip5；
  重叠窗口可重复贡献训练统计，不新增独立样本。测试折不参与归一化/类别权重/训练。

## 两个同容量训练臂

每视角共享512→8线性投影+GELU，每相邻帧对拼接：首帧双视角表征、当前减首帧、
当前减前帧、任务与时间差，共50维；共享50→16→1 MLP+GELU得到每帧对logit。
合计4937个可训练参数；不对每帧对贴窗口标签，只有汇聚后的整窗输出接受监督。

- `mean_pool`：有效帧对logit算术均值。
- `logmeanexp_pool`：`logsumexp(valid logits) - log(valid count)`，温度固定1，
  偏重较强证据；不是硬最大，也不保证能定位真正推进帧。

两臂完全相同输入、参数量、每折初始权重与训练预算，仅汇聚函数不同。每折seed为
20260920+fold_index，AdamW lr=0.001、weight_decay=0.01，class-balanced BCE，
全批量固定200次更新，梯度范数上限1。不做数据增强、早停、checkpoint选择、阈值/seed搜索；
只评最终模型，sigmoid≥0.5判advance，分数未校准。没有最终全数据部署模型。

附参照：当前标签下重新拟合原40维控制器ridge（alpha1、clip5），训练折多数类、总预测推进。
控制器参照看同一末端的实测状态，输入集合不同，不把与神经视觉臂的差异归因于架构本身。

## 评价和最小检查

主报告45窗OOF准确率、BA、stationary/advance混淆矩阵、左右任务、轨迹宏准确率、
逐轨迹胜/平/负和改对/改错窗口。另报训练准确率，暴露少样本过拟合。
对保存的同一测试模型仅做一次“全帧重复首帧”的反事实输入诊断：时间差/任务保留，
取消视觉变化，记录分类变化、分数差和指标；这是分布外敏感性检查，不证明因果运动利用。

固定重点窗#4/#39/#62/#65/#77/#100保留，不能因误判丢弃。每帧对logit只用于解释网络
如何汇聚，不称导丝轨迹、推进时刻、接触概率或已校准置信度。

最低检查：padding不影响两种汇聚；常量logit两汇聚一致；梯度有限；原45窗/10折不变；
两臂初始权重相同；重载最终模型复现预测；每窗恰有一次OOF。没有额外大测试套件/逐文件hash。

预计完整准备与20个小模型拟合1–3分钟，在4090执行。若预计/实际资源情况改变则依AGENTS
五分钟规则交用户运行；代码先顺序SCP并回读。输出独立`real10_window_response_mil_v1`，
已有结果不覆盖，中断保留并用新out完整恢复，不拼接不同配置。

## 决策原则

主要看同容量汇聚对照是否有一致的描述性改善，同时是否胜过固定参照；一两个窗口变化
不称稳定收益。无改善则停止本配置，不围绕45窗调参。即使改善也只说明开发集上的响应识别
信号，仍需独立数据才能判断泛化。45窗已被反复查看，不是新的独立测试集。
保持policy_input_allowed、formal_data_allowed、deployable、real_system_validated均false。
