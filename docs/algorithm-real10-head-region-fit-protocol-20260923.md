# 头段弱定位最小拟合协议

Date: 2026-09-23. Execution scope: diagnostic training fit only.
用户同意在原六窗粗标上推进最小可行性实验；不训练PI05、响应分类或world model。

## 问题与固定数据

验证现有冻结视觉特征加529参数定位读出，能否把概率集中到人工圈定的可见头段范围。
这不是精确分割、完整25mm头段重建、尖端定位或推进识别实验。

来源是 real10_head_segment_annotation_audit_v1 的只读人工快照。
保留 real10_spatial_aux_pair_v1 原fold0整轨迹划分：#4所在轨迹仍留出，不计算其模型输出
或参与模型选择。训练只含#39/#62/#65/#77/#100的25个有几何帧位，与旧25个有效tip监督
恰好同帧；20条两点短线、5个partial粗框。15个complete、10个partial。原6个not_visible
和1个ambiguous不训练为背景，不补画。#4的4个几何（3partial/1uncertain）保留不用。

模型输入仅为原固定场景ROI224对应的冻结ResNet18 layer1特征64×56×56。不重新裁剪，
不使用人工框/线生成输入ROI；不输入人工状态、任务角色、精确tip/contact/墙距/血管参照。
几何仅进入离线损失/指标。原响应标签、可见性、数据划分、缓存和旧checkpoint均不修改。

## 最小目标与配方

保持原SpatialResponse的project/location结构，只训练529参数；response分支冻结且不用。
不新增网络结构。每帧的允许支持域S：

- bbox：原坐标映射后落在粗框内的56×56格点；不将框内全体像素标为头段。
- polyline：到人工可见线段的距离不超过1个特征格的格点，距离在网格坐标中计算。
  这是固定离散化带宽，不是标注误差标定；不越过遮挡连接，不推断线端点身份。
- partial只约束当前可见部分，不推断完整范围。非visible/无几何帧排除损失与指标。

单帧损失为 -log(sum_{i in S} softmax(logits)_i)/log(56^2)，窗内帧平均后再五窗等权。
该set-mass目标只鼓励一个位置落在支持域，不要求整个头段都被覆盖；softmax区域外的
竞争不是像素级背景标签。总目标乘0.1以沿用旧纯定位优化量级。

固定3seed：20261020/20261120/20261220；逐张量使用旧fold0 initial_state。
AdamW lr=0.001、weight_decay=0.01、clip=1，FP32、确定性、无AMP/TF32。
各2000步，固定记录initial/200/2000；仅2000为最终读数，不选seed、步数或最好帧。
所有训练几何等权按窗聚合，不额外猜测partial置信度权重。

## 对照与指标

不重训旧模型：

1. 均匀概率分布：报告相同支持域的面积比例，避免宽框天然高命中被误当学习。
2. 不看图像的位置先验：每个视角用训练窗等权的支持域归一化分布平均；同视角每帧预测
   完全相同。它不是最优无图像基线，只用于暴露固定相机的位置偏置，不证明视觉依赖。
3. 同seed旧纯尖端2000步：在相同25帧、相同新支持域上重评估，训练步数/输入/参数/初始化
   匹配。监督形状和目标函数不同，因此不据此宣称公平的下游收益或尖端精度提升。
4. 新头段set-mass定位：同预算，报告全部seed的initial/200/2000。

主指标：支持域概率质量；峰值到人工几何的原图像素距离；峰值是否落在支持域。
另报空间期望到几何距离、归一化熵和支持域面积。线与框、complete与partial分别汇总，
不以易拟合宽框掩盖短线情况。Side/Top分别先帧到窗平均再窗平均；每seed独立读数，
然后全3seed均值和标准差。五窗全部为训练样本，不报告成功率/泛化/显著性。
目标本身是粗几何，所以距离不是精确真实头段误差；支持域命中也不是分割IoU。

不运行新的消融或泛化测试；本轮没有创新收益、解释性或部署主张。响应整合、视觉依赖
验证及LOEO留待本轮读回后决定，不以少量训练点的拟合作为启用条件。

原4090缓存不搬运；按已有纯定位计时，3×2000小分支更新加导出预计2–3分钟。

不覆盖旧out或旧checkpoint。整项意外超过五分钟不强杀，先报告进度。
