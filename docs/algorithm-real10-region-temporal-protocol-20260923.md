## 主要问题与解释边界

这是一项输入干预敏感性诊断，不是新模型训练公平对照或独立测试。首帧重复保留起始
静态外观，末帧重复保留结束静态外观；task和原dt仍在，因此不能将所有保留能力归为
图像位置，更不能从性能下降唯一归因到导丝运动（亮度、遮挡、背景变化也会消失）。

原人工标签只用于对照同一个原窗口的分数/判定保持情况，不把它声明为合成静态序列的
物理真值；不将advance改为stationary或新增标签。重复帧可能偏离训练分布。性能下降
说明对该输入干预敏感，不自动证明正确时序推理；性能保持说明不需要完整时序也能
保留部分原标签关联，但不证明模型完全未使用时序。没有接触、触觉或动作前预测结论。

## 固定报告口径

每个arm/seed/condition全部45窗一次留出推理，共810条：270条真实回放、540条重复帧
诊断。真实回放须与原保存的window/local logits及类别一致（最大绝对差<=1e-6）。
每组报告BA、准确率、两类召回、轨迹宏准确率、混淆矩阵[stationary, advance]。
重复帧指标保留原标签参照，清楚标为诊断对照分数，不是新的物理任务成功率。

对每个重复条件相对真实条件报告BA等差、类别翻转数/率、正确→错误与错误→正确数量、
平均绝对logit/分数变化、分真值类别的翻转率；逐seed和三seed均值/样本SD均保留。
另报告每condition的区域-全局差，避免把两种结构本身的静态关联能力混在一起。
六固定难例#4/#39/#62/#65/#77/#100全部seed与条件报告，不挑最好结果。

| 检验主张 | 证据 | 允许解释 |
|---|---|---|
| 已有模型对跨帧信息敏感 | 重复输入相对真实的逐窗分数/判定变化 | 该开发集中的输入依赖 |
| 区域收益是否仍存在于静态重复输入 | 各条件区域-全局配对差 | 收益可能含静态线索，不能唯一因果归因 |
| 正确导丝动力学/世界模型/部署有效 | 本轮无相应证据 | 不作此主张 |

不设看结果后调节的阈值，不搜索seed或新增更多干预。本轮结束后依据正负证据给出
下一步，不自动启动训练。45窗嵌套于10轨迹且重复使用，不把810条或3seed算成独立样本。
