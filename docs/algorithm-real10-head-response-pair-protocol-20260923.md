# Real10 头段表示接回响应识别：固定配对协议

日期：2026-09-23。用户同意推进轨迹隔离的响应识别对照。
只做离线动作后识别，不改变PI05、world model、现场模型、采集器或人工标签。

## 问题与数据

上一轮仅证明25个训练帧的头段粗标可拟合。本轮检验：定位表示冻结之后，头段弱定位
与尖端定位是否给同一响应头带来不同的整轨迹留出结果。不是比较两种目标的训练loss。

原45个响应窗口、10条真实source episode、25 advance/20 stationary及原10折LOEO不变。
标签仍是推进/未推进二分类；小幅推进、仅移动、突然跳进只作已有难例说明，不新增类别。
每折整个source episode留出；定位预训练和响应训练都只能用其训练侧。不加载上一轮
五轨迹拟合后的权重，也不在不同fold间复用训练后的定位分支。

主比较限定两种定位监督共同拥有的原25帧，来自#39/#62/#65/#77/#100：
同一帧既有旧有效tip点，也有新头段几何。每折再屏蔽留出轨迹的这些监督。
#4的4个头段几何没有有效tip对应，不放入任一组定位预训练，避免多标注帧造成混杂；
#4的响应窗口仍正常参加原LOEO。此轮不是利用全部29头段标注的最佳性能训练。
空值不填补、不当背景；partial不扩展为完整头段；原响应不复制成逐帧标签。

固定场景ROI224、RGB/ImageNet归一化、冻结ResNet18 layer1缓存和SpatialResponse结构不变。
forward仍只接收原双视角图像特征、task_right和观测时间差。人工几何、状态、诊断字段、
四点血管参考都不作模型输入，也不据此裁剪图像。

## 两组相同的训练流程

| 组别 | 定位阶段 | 响应阶段 |
|---|---|---|
| tip_frozen | 原tip Gaussian归一化CE，2000步 | 定位分支冻结，原响应头训练200步 |
| head_frozen | 头段支持域负log概率，2000步 | 完全相同 |

定位阶段只训529参数project/location，response保持初始状态；响应阶段只训原1025参数
response，project/location不再更新。这样测冻结表示的作用，不测端到端联合微调。
无新网络、无新的时间池化或物理推进规则；保留原算术均值汇聚和首帧/相邻帧差分输入。
冻结表示在训练窗口上缓存62维响应输入，必须与原完整forward一致；缓存不改变算子语义。

tip使用原sigma=1格Gaussian；head沿用上一轮框内格点/短线1格支持域。定位损失均除以
log(56²)、乘0.1，帧到窗平均再等权平均有监督训练窗；只要求当前可见部分的粗位置。
响应阶段用原balanced BCE，pos_weight仅由该折训练类别计数得出，不重新拟合阈值。

固定base seeds 20261020/20261120/20261220，fit_seed=base_seed+fold_index。
每组均加载原同seed/fold未训练initial_state，逐张量匹配；不加载任何已训练定位状态。
两阶段分别使用AdamW，lr=.001、weight_decay=.01、clip=1；FP32、确定性、无AMP/TF32。
只评2000定位+200响应的最终checkpoint，阈值0.5，不选seed、预算、阈值或最佳模型。
完整3seed×10fold×2组=60次拟合，120000定位更新+12000响应更新。

## 指标和解释

主指标：45窗OOF balanced accuracy，另报accuracy、stationary/advance召回、混淆矩阵、
整轨迹宏准确率；每seed独立报告和配对差，再报告均值与样本标准差。
矩阵真值行/预测列，类别顺序[stationary, advance]。重复seed不是新增独立样本。
固定检查#4/#39/#62/#65/#77/#100的全部seed响应分数，不能只展示改对的案例。

定位仅对25个共同有标注的留出帧报告同一头段支持域概率、峰值到粗几何距离，Side/Top
先帧到窗平均；无几何的留出折记null。图版用固定最小seed20261020展示全部25帧，
不选择好帧。单点域内命中不等于完整分割或同一物理点追踪，不据位移自动标推进。

三个BA配对差均>0且平均轨迹宏准确率差>=0，仅称本开发集上方向一致；不是显著性、
独立泛化或部署门槛。若结果混合/负面，不搜索参数，不因此扩标或升级PI05架构。
旧联合200步模型仅历史背景：与本轮冻结流程不同，不作为本轮公平主对照。
不声称接触/触觉、仿真实数混合、低可见度鲁棒性、world model或实机收益。

## 执行与证据

独立入口 tools/train_real10_head_response_pair.py；独立输出
simulation_output/real10_head_response_pair_v1；原始工件只读。
先在训练窗最多的一折做两组200定位+20响应临时计时，权重丢弃，不计算留出性能。
估算完整任务：每组定位/响应分项按2000/200步外推；定位再乘最大训练点数/计时折点数，
避免训练窗最多的fold恰好有较少定位点而低估。加冻结特征缓存开销，
共30个pair，乘1.25余量再加60秒加载/保存/汇总/渲染余量和prepare用时。
完整逻辑任务估计>300秒则交用户运行；不拆小任务规避五分钟规则。

最终小脚本/协议顺序SCP并回读后执行；大缓存留4090，不重新下载或编码图像。
每个seed/fold/arm完成后独立保存，--resume跳过完整项，中断项从固定初始化重新做。
保存配对初始状态、训练几何归属、阶段冻结检查、缓存forward和checkpoint重载一致性。
记录训练时长/显存，不逐文件SHA或新增无关smoke。

汇总导出270条OOF响应和150条共同留出几何记录及概率图。独立绘图入口
tools/report_real10_head_response_pair.py，真实数据manifest、中文450DPI PNG/SVG及HTML。
报告实现完成、验证完成和用户视觉接受三种状态；所有输出policy_input_allowed、
formal_data_allowed、deployable=false，无全数据部署权重。
