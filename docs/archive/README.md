# Documentation Archive

This directory stores historical project notes, old entry-document snapshots,
legacy command sets, and detailed experiment context that should remain
recoverable but should not be part of the default startup reading path.

Default startup should read:

```text
AGENTS.md
.codex/skills/project-2026-guidewire-mujoco/SKILL.md
docs/project-state.md
docs/handoff.md
docs/weekly-meeting-log.md
```

Use archived files only when a task needs old experiment details, older
commands, or evidence behind a compressed conclusion.

## Entry Snapshots

- `AGENTS-before-entry-slimming-2026-07-13.md`: pre-slimming project entry
  notes.
- `project-skill-before-entry-slimming-2026-07-13.md`: pre-slimming project
  skill.
- `project-state-before-entry-slimming-2026-07-13.md`: pre-slimming current
  state document with detailed experiment history.
- `handoff-before-entry-slimming-2026-07-13.md`: pre-slimming handoff document
  with detailed historical context and reference artifacts.
