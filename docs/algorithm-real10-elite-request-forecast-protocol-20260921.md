# Real10 Elite 请求条件未来预测：固定诊断协议（2026-09-21）

本协议在读取本轮模型结果前固定。任务是算法工程诊断，不是论文Results章节，也不是新的
实机或policy评估。采用实验规划skill的预先固定/可追溯原则，文档仍归算法轨管理。

## 问题和数据

检验：在已有动作前观测之外，真实Elite绝对目标请求是否包含额外的未来响应信息。
输入包固定为`real10_elite_request_response_pack_v1`的全部175个事件、10个episode；
左80/右95，38个目标xyz，固定目标姿态/速度/Piper hold。没有新增人工标签或样本筛选。

原all-train/no-validation身份保持。诊断使用包中固定的10个整episode LOEO folds，
每个事件恰好一次OOF，均匀样本权重；同时报告等权episode宏平均，以避免长度较长的轨迹
独占汇总。没有类别标签，不作分类平衡或accuracy/BA统计；不增加seed/阈值/超参搜索。
这些是相关的开发数据，且PI05已经见过这10条轨迹，不是独立测试或新geometry泛化。

## 固定预测目标

每个事件只取原1.5秒名义窗口中的**最后一条已有未来记录**，不重选窗，不插值生成图像。
末帧的实际采样时刻/视角偏差写入监督和审计，不输入预测器；这不是精确t+1.5秒的物理预测。
报告Side、Top和Elite末帧实际相对时间范围。

分开预测和报告两个目标，不合成一个“世界模型总分”：

1. **Elite实测平移响应**：该末帧相对锚点的xyz位移，单位mm。不是导丝推进、执行成功或
   共享policy动作标签；姿态不预测。
2. **双视角视觉变化**：`z_future - z_anchor`，Side/Top各512维。z为冻结的ImageNet
   ResNet18全图表征，输入为已有224px RGB，/255和原ImageNet mean/std；无新crop、
   增强、降质、finetune或BN统计更新。全图特征不是tip/contact专用表征，可能主要反映背景。

允许用未来图像计算监督特征，但未来特征不进入动作前输入；训练/验证图像的编码器相同且
完全冻结，不在全数据上拟合PCA、归一化或选择特征。

## 三组对照与固定拟合

| 组 | 预测规则/输入 | 公平性 |
| --- | --- | --- |
| persistence | 位移=0、视觉变化=0（保持锚点） | 零训练的必要基线，防止静态场景带来虚高效果 |
| observation_only | 请求前状态/历史和双视角表征，请求槽为0 | 与下一组同维度、同样本、同归一化/拟合设置 |
| observation_plus_request | 相同观测，再加入日志请求的绝对目标xyz | 只开放3个变化的请求维度，不输入执行结果/时长 |

共同观测特征固定为：

- 状态14维：锚点xyz(3)、首个过去观测至锚点的xyz变化(3)、左右任务(2)、过去控制器
  busy当前值/历史均值(2)、过去事件计数变化(1)、过去观测跨度(1)、锚点及两端历史有效位(2)。
- 视觉2048维：每个视角的锚点z(512)与锚点减首个过去z(512)。只使用请求前信息。
- 请求3维：绝对目标xyz；不含常量rpy/速度/intent/burst，不含path index、episode ID、
  事后状态或未来实际时间。不把目标差重命名为`elite_tcp_delta_6d`。

两学习组原始输入均2065维，块大小[14,2048,3]。复用既有ridge的训练折mean/std缺失
填充/缺失位规则，标准化clip5；各块及对应缺失位除以sqrt(2×块维数)，两组共同部分缩放不变。
训练折常量/全缺失列std置1，缺失值标准化后为0，并保留缺失指示。

采用**多输出ridge回归，alpha=1，均匀样本权重、不惩罚截距**。每折每学习组一次闭式求解，
合计20次；目标各维独立等价求解，不因视觉维数改变Elite目标的拟合权重。使用样本空间
dual存储，避免保存大尺寸dense系数。无epoch、early stopping、最佳checkpoint或模型选择；
seed固定20260921仅用于冻结视觉编码的确定性设置，非多seed实验。

## 指标、效率与报告口径

- Elite：xyz合并MAE/RMSE、逐轴MAE；分开报告，不等同于policy动作误差。
- 视觉：1024维合并RMSE及Side/Top分视角RMSE；任意特征单位，不是像素/mm/导丝位移。
- 三组均报告汇总OOF、逐episode和episode等权宏平均，以及左右任务。
- 请求组相对仅观测组的绝对误差变化和相对百分比；相对persistence的变化另列。
  误差下降为负值；基线为0时相对变化记null。
- 报告逐episode增/平/减（浮点比较容差1e-12）、逐事件误差变化，不作显著性或独立CI声明。
- 在预测完成之后才读取后续请求/缺历史审计，分层报告但不用于筛选、特征或模型选择；
  2个后续feed窗仅描述，不能单独作稳定统计结论。
- 记录编码图片数、编码时间、20次求解/保存时间、预测时间、完整运行时间、运行库版本。
  冻结编码+小矩阵求解预计1–3分钟，按项目五分钟规则执行；不启动PI05训练或硬件。

## 结论边界（预先固定）

只有请求组视觉误差同时低于仅观测和persistence，并且episode宏平均也同向，才记作
“视觉未来预测的正向诊断信号”；仍不称稳定创新收益或直接采用评分器。若只有Elite改善，
只说明请求与机械臂响应的对应信息，不证明导丝动力学有效。若无改善，保留负结果，不在
这175个事件上反复调参找收益。

本轮没有新增架构、非线性world model、rotation/速度/Piper/contact/tactile收益、候选动作
反事实排序、策略成功率或实机能力结论。原PI05权重、mixed-head、loss及控制器保持不变。
解释性/XAI不是本轮贡献；几何泛化和新独立真实数据验证均未执行。
