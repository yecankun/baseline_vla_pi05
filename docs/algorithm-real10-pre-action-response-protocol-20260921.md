# Real10 动作前响应预测：Piper请求配对对照

## 预先固定的研究问题与范围

给定锚点前可观测信息，加入本次Piper请求是否改善随后人工标注的推进/停滞预测？
这是观测性、小样本开发诊断，不是单动作因果效应、候选动作排序或正式世界模型验证。
仅训练小型闭式ridge分类器；不训练/修改PI05、mixed-head、world model或现场权重。

## 样本、输入与配对

- 来源：`real10_action_effect_interface_v1`的全部45窗、10个原整episode LOEO folds。
  snapshot逐项对应当前人工v2标签，不改标、不丢掉有后续动作的窗口、不建新随机split。
- 只读`queries.jsonl/model_input`构建特征。future图像/实测终点/可见性标签/执行日志/
  ID/绝对时间/采样原因不进特征；真实Piper请求从已选择的candidate字段读取，不读执行结果。
- 视觉：沿用独立ImageNet ResNet18冻结eval；只编码过去窗口**首帧和锚点**的side/top
  224px图像，无新ROI/增强。每视角`[当前512, 当前−过去首帧512]`，共2048维。
  全部feature统计仅在每折训练集拟合；不是用已见过10条轨迹的PI05提特征。
- 状态12维：当前Elite xyz毫米(3)、过去首帧至当前的xyz变化(3)、左右任务onehot(2)、
  锚点历史busy(1)、过去历史busy均值(1)、过去历史事件计数变化(1)、过去观测跨度秒(1)。
  读取既有state_32及有效mask；不输入原始绝对事件计数、不使用近常量旋转标签或未来delta。
- 请求2维：`[hold, feed]`onehot；当前所有burst=1，明确核对但不增加恒定特征。
  Elite候选仍null/无效，不填零、不进入分类器或原9维world接口。
- 主对照两组相同2062维输入槽：A请求两槽恒为0；B用实际onehot。共同状态/视觉数据
  逐值相同，block尺寸恒为[12,2048,2]，不会因加入请求改变其它特征的缩放或正则强度。

## 固定拟合、指标与统计边界

复用已有`fit_ridge/predict_ridge`：class-balanced ridge，alpha=1，未惩罚intercept，
训练折有限值mean/std填补，显式缺失位，各块除以sqrt(2×原块维数)，标准化值固定clip±5。
阈值0.5，score不是校准概率。继承已有诊断种子20260920，无随机切分、超参数/特征/
阈值/最佳checkpoint搜索，每折只闭式拟合一次。两个组都保存全部10折模型。

主指标是汇总45个OOF预测的balanced accuracy（两类recall均值）；同时完整报告accuracy、
真实行为行/预测列的2×2混淆矩阵、逐episode accuracy与episode宏平均、左右任务和
hold/feed子组。always-advance及每折train-majority仅作无需模型的参照。
报告加入请求相对A的绝对百分点差、相对变化、改善/恶化的窗口与轨迹数量、分数变化。
每个单类子组的balanced accuracy保留null，不能补0或声称无召回误差。

只作描述性配对比较，不对45个相关窗口作独立样本检验，不把交叠训练集的10折当独立
重复试验计算显著性；不搜索p值。31/14个有/无后续动作记录窗口只在预测完成后作预定
审计分层，不筛数据、调参或作为输入。无后续记录不等于无其它实际运动。

这45窗曾用于多轮开发，LOEO是此分类器的episode隔离，不是新的独立测试集。少样本
无收益不能证明请求或更强的非线性效应模型无用；线性请求项只提供加性偏移，不足以
证明学到了状态相关动力学或反事实动作收益。

## 效率、验证和交付

过去已有602图ResNet提取约1.68秒；本轮至多180张不同图、20个<=44样本闭式求解，
预计全任务小于1分钟，低于5分钟用户运行阈值，按本次授权直接在4090执行。
只使用现有缓存权重，不自动下载；先SCP最终小文件并回读，再远端执行。

必要检查集成于一次运行：snapshot/folds匹配；图像与状态时间不晚于cutoff；只有请求
块不同、训练折共同标准化不变；目标/审计字段不作为features；预测覆盖45窗。
不新增大量smoke、SHA或硬件测试。保存protocol/features/fold_models/oof_predictions/
report，fresh目录拒绝覆盖；失败保留目录，新路径重跑短任务，不续训或覆盖旧工件。

结果图固定为两组accuracy/balanced accuracy及两张混淆矩阵；先读真实JSON再生成
中文450dpi PNG/SVG和data-manifest，不用模拟数值。implementation、verification、
用户视觉接受分别记录；图未经用户确认不能标accepted。

## 决策口径

明显且跨轨迹一致的诊断收益：只能支持继续研究请求条件的前瞻响应模型；仍不能替代
完整Elite指令监督或跳转到现场动作选择。收益集中/无收益/不确定：记录具体错例与混杂，
不立刻扩大模型或在这45窗上搜索到正结果。原现场PI05始终保持默认。
