# Real10 同预算联合目标对照：训练内拟合

执行前固定，2026-09-22。用户同意补齐与纯定位相同的2000步联合训练对照。

## 最小问题与比较

旧联合模型仅训练200步，而纯定位已固定训练2000步。因此不能把两者差异直接归因于
联合目标。本轮只补缺失的 `joint_2000`；不重跑旧200步或纯定位，不搜索模型/权重/seed。

| 组别 | 目标 | 更新数 | 来源 |
|---|---|---:|---|
| joint_200 | 原response BCE + 0.1定位CE | 200 | 已有旧fold0权重及纯定位诊断读数 |
| tip_only_200 | 0.1定位CE，response冻结 | 200 | 已有纯定位试验 |
| joint_2000 | 原response BCE + 0.1定位CE | 2000 | 本轮唯一新增训练 |
| tip_only_2000 | 0.1定位CE，response冻结 | 2000 | 已有纯定位试验 |

## 固定条件

- 原source：`simulation_output/real10_spatial_aux_pair_v1`；比较来源：
  `simulation_output/real10_tip_only_fit_v1`；新out：`simulation_output/real10_joint_budget_fit_v1`。
- 原fold0的36个训练窗口/9条轨迹；原9个留出窗口不进入训练、评估或模型选择。
  25个tip点/5窗/5轨迹全部属于训练侧，Side13点/5窗，Top12点/4窗。
- 完全复用 `train_real10_spatial_aux_pair.fit` 和 `response_losses`，仅给原fit传入2000步。
  原空间结构1554参数、冻结ResNet18 layer1缓存、输入/task/时序、Gaussian sigma1、
  点先按窗平均的定位CE及系数0.1不变。原response class weight仍由36个训练窗口计算。
- 原三个seed：20261020、20261120、20261220。新初始化须逐张量等于旧fold0的initial_state。
  不从纯定位或旧200步权重热启动，因为旧checkpoint没有优化器状态；从原初始化重放完整预算。
- 原AdamW lr=.001、weight_decay=.01、clip1、FP32、确定性CUDA；无AMP/TF32、无早停。
  只保存最终2000步，不选最好结果。三seed共6000新更新。
- 此处“同预算”是优化更新数相同，不是wall-clock或FLOPs相同。纯定位只处理25张点图，
  联合训练处理36个完整窗口，保留这一已知计算量差异。

## 验证与产物

核对输入冻结快照、三seed初始化及保存模型回放；保留旧文件size/mtime，禁止覆盖。
不再额外运行新的smoke suite。新结果的逐点计算和前轮一致（空间分布期望及诊断argmax），
同时比对其与完整forward的logits/坐标浮点差。response BCE仅作为训练目标分解记录，
不计算新的响应BA或留出指标。

每相机、每seed：点在窗内平均→窗宏平均；最后报告全部3seed及描述性均值。
指标为原图期望/峰值误差、目标归一化CE、熵及目标两格邻域概率质量。
两格来自原Gaussian宽度的两倍，不是定位合格阈值；px不换算为mm。

中文汇总图显示全部三seed/四组；案例固定沿用每窗每相机最早有效tip（9组），展示
joint_200、joint_2000、tip_only_2000，不挑好帧。新热图仅导出这27张；旧热图直接复用
上轮本机包，避免冗余传输。完整25点评估全部保留，不因展示选择删样本。

预计计算：旧试验为60 fits、12000更新、180s；本轮6000更新约90s，
加缓存/验证/绘图余量，完整逻辑计算预计不超过3分钟，按项目五分钟规则由agent执行。
SSH中断时 `--resume` 跳过完成seed，未完成seed从固定初始化重跑；不删除旧结果。

## 判读边界

| 观察 | 允许判断 | 尚不能判断 |
|---|---|---|
| 联合2000比联合200好 | 增加预算对联合训练内拟合有帮助 | 泛化/创新/实机收益 |
| 同2000步联合仍差于纯定位 | 步数差异不足以单独解释差距 | 具体是梯度冲突、loss比例还是限幅 |
| 联合2000接近纯定位2000 | 原短预算是重要混杂，暂不改联合架构 | 所有困难例已解决或更多数据无用 |

只检查训练内拟合，不进行独立泛化/鲁棒性/XAI研究，不新增或修订标签。
原PI05/mixed-head/world model、控制器、数据采集与共享接口不动。
`policy_input_allowed=false`、`deployable=false`；训练点不能当独立测试样本。
