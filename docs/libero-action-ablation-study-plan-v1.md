# Native LIBERO 动作信息消融：训练前协议

日期：2026-09-12。当前仅完成规则、适配器及缓存元信息检查；未开始新数据获取、
特征提取或本研究训练。机器可读协议为同名 JSON，SHA256：
`210ff8bbb75e3316620590cda9e5067f7447125acddb53ae7fe751bea01810ac`。
不修改已完成的两条 episode 试验、模型、损失或冻结协议。

## 要回答的问题

在相同观测历史、初始参数和优化预算下，真实候选动作信息是否比“没有逐样本
动作信息”更有助于预测未来状态？这不是动作因果效应、策略成功率或低可见度
鲁棒性试验。此前验证状态 MAE 改善、视觉 MAE 退步的结果保持原样。

## 前瞻数据划分

- 固定原公开数据版本、native task9/source task39；排除1400、1401、1402。
- 先补齐1693条 episode 的任务归属，只解释 ID、task、frame、global index、
  timestamp 列，不根据动作、状态、图片、奖励或新模型结果选择样本。
- 用固定 SHA 排序选12条新完整 episode，前8条训练、后4条验证。实际 ID 目前
  **未确定**；候选任务索引不全时不得从已缓存子集暂选。整单超过12000行就拒绝，
  不截断轨迹，也不改选较短样本。
- ID 清单与哈希先保存，再进行全帧/时序/任务一致性、两视角视频区间及所有
  episode pair 的重复检查。复用7状态+6连接动作的精确/量化窗口检查与联合双视角
  7帧窗口哈希；另检查新候选与旧1400/1402开发轨迹的重叠。失败保留原 ID，
  不看过数据之后悄悄替换。
- episode 隔离不等于已证明 family 独立。报告已知轨迹组及实际独立组数；
  同一验证组有多条重复 episode 时不能称为多个独立验证样本，同时报告组级结果。
  PI0.5 特征权重与公开演示的训练重叠仍未知。

## 公平对照

| 对照 | 动作输入 | 保持不变 |
|---|---|---|
| observed_action | 原 train-normalized 候选动作 | 观测、task、targets、模型及损失 |
| normalized_zero_action | 训练和评估均全零 | 同上；零代表训练动作均值，不是物理停止/hold |
| persistence | 不需要动作；重复当前视觉特征、状态残差0 | 同一评估窗口与有效性支持 |

未来预算先固定为3个 seed × 2个学习对照 × 200步，共1200次更新；这只是设计，
尚未授权执行。每个 seed 内两对照共享完全相同的初始参数、归一化、组/episode/
window 采样序列、AdamW设置和最终200步检查点规则。归一化仅来自8条训练轨迹。
不只在评估时遮动作，不选择最佳验证检查点，不追加步数或调损失权重。

主指标为每验证 episode 的 normalized8D state MAE，先等权汇总 episode，再报告
3个 seed 的配对差异与描述性均值/标准差。并列报告视觉 MAE/RMSE、masked objective、
各 horizon/view/state 维度、组级结果和样本量加权汇总，避免只展示有利分支。
只有三个 seed 的主指标均优于零动作对照且优于 persistence，才描述为该开发划分
上的动作信息预测增益；仍不宣称统计显著、泛化、因果控制或策略改善。

## 已实现与当前缺口

`tools/pi05_libero_action_ablation.py` 只接受原生六输入，复制独立张量后变换动作。
不接收 targets/metadata，不向模型注入对照标记；先检查原动作有限值，不能通过
零化掩盖损坏数据。20项合成前向测试证明零动作对照对原动作变化严格不变。

`tools/plan_pi05_libero_action_ablation.py` 已在远端投影缓存索引。完整元表1693条，
仅6条已有任务归属，缺1687条，涉及376个未缓存任务索引分片。当前任务可用的两条
恰为旧1400/1402，因此新增可选数为0、split为null；没有假造12条 ID。

下一步是单独完成**任务索引获取与预算审计**：核对固定版本下376个分片的大小、
哈希与必要列读取方式，先给出总预算；不下载视频或提取特征。Parquet文件即使含
动作/状态列，任务归属扫描也只解释上述五列。全文件下载与列投影的传输字节量
应分别报告，不假称网络只传了任务字段。任何超过100MB的单文件/归档交用户传输。
之后才能生成确切12条清单及所需 payload 清单，进入完整性/重复检查门。

多 episode 数据准备、特征包、分组采样哈希、消融训练入口、最终结果汇总尚未实现。
不能通过移除旧固定两条 episode 入口的校验来复用旧训练命令。

本协议使用项目 skill 约束轨道与执行边界；实验结果规划 skill 用于冻结公平对照、
指标、消融及允许结论。没有编写论文 Results/Discussion、虚构结果或生成示例图表。
