# Real10 推理审核第一版：离线回溯验证

日期：2026-09-29。用户授权验证“推理审核 + 现有 π0.5”的第一版。
范围：算法轨，使用已有现场记录；不连接硬件、不运行策略、不修改权重或控制器。

## 固定样本与证据边界

完整纳入四次模型动作运行，不按判断难易筛选步骤：

- `real10_once_demo_20260924_112930`：1 个候选动作。
- `real10_bounded_demo_20260924_114052`：1 个候选动作。
- `real10_bounded_demo_20260924_115218`：3 个候选动作。
- `real10_operator_steps_20260924_120458`：11 个候选动作。

共 16 个候选动作，相关样本来自同一现场，不能视作 16 个独立任务。
固定路径回退运行排除：其 Elite 执行动作并非 π0.5 输出。
本次代理已读过现场总结，包括方向偏差和过期观测事件；这是有历史先验的
回溯流程验证，不是盲测、独立泛化评估或成功率实验。

## 审核流程

`tools/review_real10_reasoning.py prepare` 只导出白名单动作前字段、当前 before
双视角，以及本次运行中更早的 before 观测。当前/未来 after 图片、动作结果、
停止原因、到位误差、ACK 和任务标签不进入审核输入。落盘最终 report 文件本身
包含事后数据，故只能声称字段隔离，不能声称历史代码版本或全时序已精确重演。
保存图像是降采样预览，不是原始分辨率，也不是曝光同步的双目测量。

参考 `path/path1_pose.txt` 只表示左任务的一条记录机械臂路径。向最近非退化线段
前进方向的点积用于对照，不是导丝推进真值，也不证明唯一正确动作方向。
此参考的选择来自既知历史，属于显式提供的额外先验。
审核者同时可见规则输出，故规则一致性只是行为描述，不是两个独立评审者的准确率。

代理实际查看每张 before 图和结构化输入后，逐条记录以下一种建议：

- `continue_candidate`：没有足够证据新增拦截，仍需原控制器检查与现场监督。
- `pause_review`：存在需人工核实的矛盾，建议暂停候选动作。
- `observe_again`：本次图像/状态不足以支持任务判断，建议补充观测。

每条保存简短证据、局限、视觉观察、是否仅靠规则即可作同样判断。
禁止从磁臂位移或 UDP ACK 推断导丝实际推进；禁止把血管/导丝不可辨识解释为
确定碰壁；禁止以事后图像修改已提交的动作前建议。
这版审核由当前 Codex 会话完成，并非自动 API 守护进程，也不模拟一个未调用的 LLM。

## 两项对照与完成条件

1. 既有程序：从结果记录读取是否真正下发、是否到位、是否发包和停止原因。
   结果只在代理建议全部提交后汇总。到位不等于动作对任务正确。
2. 同信息简单规则：非有限/超限/不支持意图等拒绝；参考路径方向点积为负，
   或 feed 缺少有效控制器历史时暂停。观测时间戳存在但缺少下发时刻时，
   不臆造过期证据。规则是本轮新增的比较基线，不冒充历史控制器行为。

报告全部 16 条建议、候选覆盖、规则一致性、与原程序下发的差异，以及每项
差异的证据来源。只对有外部逐步任务标签的条目计算误拦率/漏检率；标签缺失时
指标必须为 null。不能把零额外许可、暂停全部动作当作更安全或更好。

同一日志上假设拦截某步后，后续步骤仍只作独立 shadow 审核：它们依赖实际历史，
不是拦截后的反事实轨迹。离线用时不代表在线时延；高层判断后须重新采集并核对
状态，不能放宽当前 2 秒观测限制。

交付输入包、人工/代理审核 JSONL、自动统计报告和可打开的中文 HTML。
执行必要的字段隔离、全覆盖和统计核查。实现、验证、用户视觉接受分开记录；
图像由代理查看不等于用户接受。预计准备/统计数秒，无训练或长计算。
