# Real10：训练匹配的首帧静态参照 vs 已有时序模型

日期：2026-09-23。用户批准继续上一轮提出的静态参照对照。先固定本协议，再看结果。
仅算法轨离线响应识别，不改模型结构、人工标签、PI05、现场权重、控制或数据/SOFA轨。

## 问题与固定比较

上一轮只在推理阶段重复首帧，存在输入分布偏移。本轮静态模型在训练和留出评估时均
只读取窗口首帧的同步Side/Top观测，预测原窗口响应标签。原窗口标签不改为静止；
重复首帧是信息消融，不是声称实际采到了静止序列。

主比较是regional_4x4的static_first与temporal_sequence；同时补齐global_broadcast
的同一静态参照，以区分区域表示优势与帧间视觉变化优势。两臂各30个新静态拟合，
共60个新拟合；60个已有时序拟合只读复用，不重训，不选择最好seed或checkpoint。

来源simulation_output/real10_region_response_pair_v1；输出
simulation_output/real10_static_temporal_pair_v1。原45窗、25推进/20未推进、10条整轨迹
10折LOEO，3seed 20261020/20261120/20261220不变；缺失标注仍为null/原mask。

## 输入、初始化与训练预算

- 两条件保留原task、观测dt、序列长度及有效mask；“单帧”指一个同步双视角时刻，
  不是单摄像头。dt来自完整窗口，所以静态参照仍不是纯图像或在线动作前预测器。
- 在逐帧冻结编码器缓存中重复首帧，再完整执行原定位器/区域矩/响应forward。
  无时序编码器，等价于重复图像；训练及评估使用同一变换，不使用末帧。
- 每个seed/fold/arm只从对应旧checkpoint取529参数的冻结project/location和
  未训练的response_initial。不从拟合后的response继续训练。验证原train/test索引。
- 原RegionResponse保持1058→8→1、8481可训参数，529定位参数冻结。相同初始张量、
  AdamW lr0.001、weight_decay0.01、clip1、FP32确定性、无AMP/TF32/dropout。
- 两条件均固定200次全训练窗更新、末步、阈值0.5、训练negative/positive加权BCE。
  原时序模型已有200步；新增静态模型也仅200步，共12000次新更新，定位更新0。
- 静态组单独在本折静态训练特征的有效项上拟合mean/总体std，下限0.001；不沿用
  时序归一化，也不使用留出数据拟合。时序组保留原训练归一化和最终权重。
- 原时序特征为352维首帧、352维相对首帧差、352维相邻帧差、task/dt。静态组704维
  差分均为0，训练mean也应为0、std下限0.001。参数总数相同不等于有效输入秩或
  有效函数容量相同；这属于信息消融，不能声称完全等效的有效容量比较。
- 不增加平滑或连续运动约束，允许停顿—突进—停顿；不生成逐帧响应/接触标签。

## 指标与判定（结果前固定）

逐seed报告45窗OOF BA、准确率、轨迹宏准确率、推进/未推进召回及混淆矩阵，
矩阵真值行/预测列，顺序[stationary, advance]。报告三seed均值/样本SD，以及每种
表示的时序−静态差、每种输入的区域−全局差；单位百分点（pp）。
六难例#4/#39/#62/#65/#77/#100全部seed输出，不挑案例、不用它们调阈值。

主要描述性一致改善条件：regional_4x4的三seed时序−静态BA差均>0，且平均轨迹宏
准确率与未推进召回差均>=0。该条件不是显著性、独立测试或部署门槛；类别取舍仍要报告。
满足只支持本开发集跨帧视觉信息增益，不能证明正确物理动力学；不满足则不将上一轮
区域收益解释为可靠时序建模，不扩大当前结构/seed/步数搜索。本轮结束后不自动开新训练。

45窗嵌套于10轨迹；3seed不是135个独立样本。开发集已反复使用，没有新泛化/鲁棒性
数据、动作前因果效应、接触触觉或实机证据。静态模型可利用起点外观、任务及dt关联；
时序模型还可能利用亮度/遮挡/背景变化，提升不自动证明识别了导丝推进。
