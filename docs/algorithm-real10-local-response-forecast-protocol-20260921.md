# Real10 Elite请求：固定局部响应预测协议（2026-09-21）

在本轮提取/拟合结果产生前固定。算法工程诊断，不撰写论文Results/Discussion；采用实验
规划skill的预先固定原则，结果和命令仍归算法轨。没有新增PI05/world神经网络训练或部署。

## 范围与唯一预测任务变化

源为`real10_elite_request_response_pack_v1`全部175次请求、10个episode、原整episode
LOEO folds。仍是相关开发轨迹，原all-train身份、人工标签和PI05权重不变。上一轮
`real10_elite_request_forecast_v1`的两组2065维输入缓存原样复用：14维状态、2048维动作前
全图视觉、3维请求槽。仅观测槽为零，请求组为日志中的绝对TCP目标xyz。**不增加新的局部
输入，不重编码ResNet，不把未来光流或质量标记倒灌输入。**

本轮把预测目标改为血管附近的局部运动代理。不同目标的单位不同，不能直接拿本轮误差
与上轮全图特征RMSE比大小并声称提升。宏动作仍不是PI05逐步delta，没有自动语义转换。

## 冻结的局部监督提取

直接复用`run_real10_response_local_motion.py`的`crop_original`、`pair_motion`及参数，
并读取`real10_response_local_motion_v1/preview_arrays.npz`中既有interior/rim掩膜。
校准帧、色阈值、LK参照带、Farneback、网格全部不变；不重新拟合或调区域。

- 原图1920×1080；Side ROI=[0,540,1440,1040]，Top=[480,560,1920,1080]；按比例
  缩至720×250/720×260。仍不是新增、更紧的目标血管包络。
- `real10_target_vessel_region_review_v1`草案尚未用户验收，本轮**不读取或应用其新掩膜**。
- 每视角固定2×6网格，参考带LK中位平移从稠密光流减去；候选像素为原冻结区域内的
  暗线启发式。不是语义导丝分割，可能包含磁铁、血管纹理、反射和非轴向运动。
- 从请求前锚点图像到包中最后未来记录，使用全部原有相邻帧对及各相机实际dt；保留每对
  dx/dy平均速度与平均速度模长，按dt加权均值。共2视角×12格×3量=72维，单位均为
  缩放ROI像素/秒。无目标标准差、p90、外观强度变化或人工advance标签。
- dx/dy为图像有符号方向；下降/横移不等于导丝沿血管推进。平均速度模长不是净推进速度。
- 原名义1.5s窗口不重选、无未来插帧。起点是锚点相机时间，终点是已有末帧相机时间，
  因而不是精确动作执行起点或精确1.5s动力学。实际未来时刻与跟踪质量只作监督审计。

每格必须在该窗**所有帧对**上均通过原参照跟踪和至少8个候选像素要求，才有本轮监督；
否则该格三维均为NaN/无效，不填0、不把缺观测标stationary。保留所有175窗及原folds，
报告逐视角/网格/episode监督覆盖率和无效原因，不依据预测效果筛样本。此共同有效性掩码
只用于监督loss/评估，不是预测器输入。仅有部分帧对有效的原始统计及覆盖率保留审计。

## 对照与拟合

固定三组主对照：`persistence`（局部运动=0）、`observation_only`、
`observation_plus_request`。另报告零特征的`train_mean`，只取各训练折每个目标维度均值，
检查改善是否只是学会平均场。没有seed、alpha、clip、区域或目标选择搜索。

两学习组复用上一轮各自fold的**输入归一化参数**（mean/std/scale/clip），不读取其已学
输出系数作为新预测器；alpha=1、不惩罚截距、样本均匀权重保持。每个输出维度只用该
训练折内有效监督行拟合；同有效行掩码的列合并求解，数学上等价于逐输出独立ridge。
同一输出的两组训练行相同，共同输入归一化应一致。

目标始终全缺失的维度保留为不支持（NaN），不能伪造真值。某个测试有效目标若训练折
少于2个有效值，停止该轮评价并报告覆盖障碍，不能删掉该目标来制造公平性。模型给出的
负速度模长不作事后截断，单独报告比例；这是线性预测的物理局限，不直接交给控制器。

## 预定指标与决策

主指标：有符号二维平均局部速度向量的EPE，即逐有效格欧氏误差均值，单位ROI px/s。
次指标：向量分量MAE/RMSE、平均速度模长MAE/RMSE。分开报告Side/Top、左右任务、
逐episode、等权episode宏平均；同时报告每窗等权主指标和175条逐事件误差。
不存在accuracy/BA、方向成功率或contact标签，本轮不引入阈值。

对请求组相对仅观测、零运动、训练均值分别报告绝对/相对误差变化；逐episode增/平/减
容差1e−12，不把相关窗口当独立试验。后续feed/缺历史分层仅在预测完成后读取，不影响
拟合或选择。不作显著性、独立泛化或真正导丝监督有效性的声明。

只有请求组主EPE在pooled和episode宏均值上均低于其余三组，且速度MAE相对仅观测没有
恶化，才记局部代理的正向诊断信号；否则记无明确增量/指标取舍，不调参重试。即使通过，
也不采用评分器，不宣称导丝推进、碰壁、tactile、策略成功率或实机收益。

可视化固定取每个episode按源顺序居中的请求，共10个窗，展示原ROI锚点/末帧及观测运动
箭头；不是生成未来图像或按改善挑案例。待用户验收的新血管区域仍独立挂起。

## 执行、工件与恢复

原图仅本机可用，沿用已有局部运动流程：最终脚本和协议先顺序SCP、远端入口回读；本机
`.venv`只提取数值监督并绘图，随后把小数值包上传，在`project4090`的`project2026-pi`
内拟合。没有本机LeRobot/模型训练。参考此前514帧对39秒，本轮1970帧对预计约150秒，
加上拟合/绘图，完整计算预计2–4分钟，按项目五分钟规则由agent执行；超过估计先报告进度。
不传原图或任何>100MB文件；未来大文件仍由用户传。

- 监督包：`simulation_output/real10_elite_local_response_targets_v1/`，含固定协议、完整源
  query/target/fold快照、72维监督/有效位、逐对质量、冻结掩膜和10窗预览缓存。
- 结果：`simulation_output/real10_elite_local_forecast_v1/`，含20个fold-arm模型、OOF预测、
  完整覆盖/指标/配对报告；结果PNG/SVG及数据清单仅绘制真实指标。
- 已存在的prepare/evaluate输出拒绝覆盖；失败保留错误和工件，修复/同步后选新目录，
  不修改旧包、旧模型或标签，无超参搜索或长训练resume。

协议只归算法轨；源数据、采集器、仿真专家、数据/SOFA轨、共享接口不改。policy/formal/
real-system标志false；不增加无跨轨依据的周会效果结论。
