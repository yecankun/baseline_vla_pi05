# Real10 纯定位拟合能力试验（训练内诊断）

状态：执行前固定，2026-09-22；用户已同意前轮提出的纯定位拟合试验。

## 要回答的问题

不升级架构、不新增标签、不改变冻结特征，去掉响应分类目标后，原空间定位分支能否
拟合已有人工尖端？这不是响应识别、独立轨迹泛化或策略收益实验。

## 固定输入与预算

- 输入来自 `simulation_output/real10_spatial_aux_pair_v1/source/` 的冻结快照及该目录的
  `feature_cache.pt`，不重编码图像、不下载模型。
- 只对原25个有效tip点（5窗、5轨迹；Side13/Top12）优化。未知点仍null/masked，
  不补点、不用material landmark、不扩充窗口。五窗是既有困难案例选择，不能代表总体。
- 这些点全部属于旧fold0训练侧；不改旧split，不计算任何留出指标。
- 仍为 `SpatialResponse.project/location`：冻结ResNet18 layer1特征，64→8→1的原定位分支，
  529个可训练参数；原1025参数response head冻结且不用，不改原模型文件。
- 三个seed固定为20261020、20261120、20261220，逐seed读取旧fold0的 `initial_state`。
- 保留原Gaussian sigma=1格、归一化CE、窗内点平均再5窗平均、系数0.1。
  唯一目标为 `0.1 * localization`，没有response BCE。点坐标只作target，不进入forward。
- AdamW：lr=0.001，weight_decay=0.01，梯度范数上限1；FP32，无AMP/TF32，确定性CUDA。
- 固定记录初始化、第200步、第2000步。200步用于同预算比较；2000步是预先固定的
  预算诊断，**不能当作对旧200步联合训练的公平性能胜出**。不早停、不挑最优seed/step。
- 共3条优化轨迹×2000步=6000更新；只处理25张已有特征图，预计整体计算少于3分钟，
  按项目五分钟规则由agent执行。若SSH中断，保留全部文件；`--resume`跳过完成的seed，
  未完成seed从同一初始化确定性重跑，不累计其旧日志。

## 比较和验证

旧联合模型固定取原fold0的 `spatial_window_tip_aux` 第200步。新旧在完全相同25个
训练点上比较；不是前轮“每点9个训练折平均”的表。新旧初始化、定位目标、优化器
相同，但去掉分类后全局gradient clipping的结果可能变化；不能把结果直接称为已证明
“梯度冲突”。点批量计算需对照原完整forward与loss，记录浮点最大差。

保存6份新checkpoint及3份完整seed结果，不覆盖原checkpoint。检查response参数未变、
保存重载输出一致、旧源权重size/mtime未变。所有结果仅为训练内拟合。

## 指标、图表和允许结论

每个seed/阶段分别按相机统计：先窗内点平均，再窗平均（Side5窗、Top4窗），最后
描述性汇总全部3seed。25点不是独立同分布样本，不做显著性或总体成功率推断。

- 原空间期望定位误差、离线argmax误差（原1920×1080图px，不换算mm）。
- 目标归一化CE及目标自身熵下界；全均匀分布CE=1作参照。
- 目标两格邻域概率质量、分布熵；两格来自原编码sigma的两倍，不是正确性阈值。
- 固定全部三seed的loss曲线和训练定位误差；每窗/视角最早有效tip（9组）展示三seed，
  不挑最好帧；图中明确“全部为训练点，不能证明泛化”。输出中文PNG/SVG及data manifest。
